# LH-012 — Admin live ops & game configuration

Status: `planned`  
Index: [README.md](./README.md)

## Intent

Extend the LH-004A admin foundation so operations can configure and observe the live game without redeploying clients or inventing fake analytics.

## In scope

- Safe live-match operational views / limited intervention (PO-defined: e.g. halt)
- Game configuration: hearts, durations, energy thresholds — versioned + audited
- Real reports from backend aggregates (fail rates, match counts) — **no fabricated numbers**
- Permission model extensions for live_ops / content_manager as needed

## Out of scope

- Challenge Studio (LH-006) duplication
- Translation publishing (LH-007) duplication
- Revenue / payments
- Exposing resume tokens, answers, serverConfig, secrets

## Exit criteria

- Change a published game rule → next match observes it
- Audit trail for config and interventions
- Dashboard/report privacy tests remain green

## Depends on

LH-004A; preferably LH-006 for config/content cohesion
