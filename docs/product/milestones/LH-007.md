# LH-007 — Mobile translation publishing

Status: `planned`  
Index: [README.md](./README.md)

## Intent

Gameplay/mobile copy is server-managed via versioned catalogs, per `PROJECT_RULES.md` and ADR-004.

## In scope

- Admin Translation Management for mobile/gameplay keys
- Immutable publish, device download/cache, match-pinned catalog version
- Replace remaining hardcoded playable/pre-match strings with keys
- Fallback order: pinned locale → Arabic in pin → last-known-good cache → bootstrap → safe unavailable

## Out of scope

- Mid-match catalog replacement
- Translation network I/O inside the 3–8s challenge execution window
- Voice challenge content
- Executable/HTML translations

## Exit criteria

- Publish Arabic catalog → next match shows updated copy
- Production path never shows raw keys
- Automated tests for pin + fallback + corrupt catalog rejection

## Depends on

LH-006 recommended (shared publish mental model); LH-001A localization boundary
