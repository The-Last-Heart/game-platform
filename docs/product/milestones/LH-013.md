# LH-013 — Visual polish & accessibility pass

Status: `planned`  
Index: [README.md](./README.md)

## Intent

Enforce reference-pack design rules across all **shipped** mobile screens and close accessibility gaps for sensor/audio challenges.

## In scope

- Visual QA vs reference boards/screens for everything delivered through LH-012
- Reduced-motion alternatives for UI motion
- Settings alternatives for shake/tilt/audio challenges (pack rule 9)
- Confirm: one primary CTA, readable challenge copy under one second, HUD always visible in challenges
- No translation fetches during challenge execution window

## Out of scope

- New game modes or screens not already shipped
- Store / seasons / voice product line

## Exit criteria

- PO visual + a11y sign-off against the reference pack for the base product
- Automated regression still green
- Document residual known deviations (if any) with PO approval

## Depends on

LH-005…LH-012 content that is considered “base”
