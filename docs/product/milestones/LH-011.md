# LH-011 — Matchmaking & private-room productization

Status: `planned`  
Index: [README.md](./README.md)

## Intent

Harden public matchmaking and private rooms into production-shaped join paths on top of LH-005 UI and LH-002/003 lobby behavior.

## Reference screens

Primarily **05** (matchmaking) and **06** (private lobby), plus host ready rules from **07**.

## In scope

- Public queue: enqueue, timeout, cancel, fair fill to six
- Private rooms: codes, host controls, ready checklist
- Reconnect into lobby without breaking match recovery
- Capacity fixed at six unless PO changes match rules

## Out of scope

- Friends list / social graph product
- Ranked MMR (unless PO explicitly adds)
- Cross-region multi-cluster matchmaking infrastructure

## Exit criteria

- Two join paths stable under disconnect/reconnect tests
- No regression to playable slice / powers if already present
- Clear client error states (full room, invalid code, queue cancelled)

## Depends on

LH-005, LH-003
