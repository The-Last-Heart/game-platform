# LH-004A — Administration Authentication and Operations Foundation

Status: done (RC1 baseline)
Day: completed before the five-day release window
Commit family: admin foundation / LH-004A-R1 (historical)

## Product outcome

Operators can sign in to a bilingual administration control center with real authentication, sessions, CSRF/origin protection, RBAC, administrator management, immutable audit, system health, and honest live-match aggregates — without Challenge Studio, content publishing, or live intervention product surfaces yet.

## Why this remains authoritative

LH-010 and LH-011 extend this control center. They must reuse the existing admin auth, BFF cookie model, roles/permissions, audit, and `/api/admin/v1` envelope patterns. Do not introduce a second admin auth stack or client-only permission theater.

## Delivered baseline

- PostgreSQL admin users, sessions, and audit with migrations and bootstrap CLI
- Nest `/api/admin/v1` admin API
- Admin-web BFF with HttpOnly session cookies, CSRF double-submit, and Origin validation
- Routes: login, dashboard, administrators, audit-log, system, profile/security
- Roles including super_admin and supporting operator roles used by later Studio/ops work
- English/LTR default with complete Arabic/RTL document switching for shipped routes
- LH-004A-R1 hardening: stale session, multi-session revoke, origin/loopback equivalence, audit sequence, Jest teardown safety

## Product rules established here

- Authorization is enforced server-side
- High-risk admin actions require permission and leave audit where already modeled
- No secrets, session tokens, or CSRF secrets in client-readable storage beyond the approved cookie model
- Dashboard numbers that exist must be real; empty/loading/error states are honest
- Admin UI dictionaries stay separate from mobile localization catalogs (LH-006 / LH-010)

## Explicitly left for later milestones

| Concern | Owned by |
| --- | --- |
| Minimal content-release management surface | LH-006 |
| Full Challenge Studio, localization center, catalog composer, challenge analytics | LH-010 |
| Live Operations, Match Explorer, player support, executive ops dashboard depth | LH-011 |
| Feature flags / global controls beyond foundation system health | LH-011 |
| Security/resilience matrices and production admin packaging | LH-012, LH-013 |

## Out of scope (still excluded from this foundation)

- Challenge Studio visual editor and device playtest
- Translation publishing product
- Game-rule / power-release editing UI
- Live match halt, queue pause, bot-fill controls (productized in LH-006 emergency controls + LH-011)
- Fabricated analytics or decorative counters
- Production cloud deployment programs

## Acceptance (historical — already satisfied)

- Login, session, CSRF, and origin protections work for mutating admin routes
- Administrator lifecycle and self-protection rules exist for the foundation set
- Audit is immutable and filterable for foundation actions
- System health and live aggregates do not invent records
- EN/LTR and AR/RTL work for shipped foundation routes
- Admin/backend integration coverage for the foundation remains a regression gate

## Handoff

Preserve the foundation. Content and live-ops product depth start in LH-006 / LH-010 / LH-011 after LH-005.
