# LH-001 — Monorepo & platform foundation

Status: `done`  
Index: [README.md](./README.md)

## Intent

Establish the monorepo, toolchain, local infrastructure, shared contracts package, and localization boundaries for mobile and admin.

## Delivered (summary)

- Apps: `mobile` (Flutter), `backend` (NestJS), `admin-web` (Next.js)
- Packages: `@thelastheart/contracts`
- Local PostgreSQL + Redis via Docker Compose
- Admin EN/AR localization architecture
- Mobile server-managed translation boundary + bootstrap fallback
- Project rules, ADRs, review-archive tooling

## Out of scope (historical)

Gameplay networking, full admin product, challenge content, production cloud.
