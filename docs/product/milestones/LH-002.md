# LH-002 — Authoritative Realtime Match Core

Status: done (RC1 baseline)
Day: completed before the five-day release window
Commit family: realtime match core (historical)

## Product outcome

Six concurrent clients can participate in a server-authoritative match over realtime transport with stable phase ordering, inclusive deadlines, hearts and energy accounting hooks, spectator transition, winner/halt semantics, and reconnect snapshots.

## Why this remains authoritative

RC1 gameplay milestones extend this core; they must not replace it with client-authoritative outcomes, arrival-order “skill,” or divergent handwritten protocol types. Product invariants in the roadmap README and [RELEASE-BOUNDARY.md](./RELEASE-BOUNDARY.md) refine the rules this core already protects.

## Delivered baseline

- NestJS match gateway, domain engine, and match store
- Shared realtime contracts consumed by backend and mobile
- Lobby / challenge / result phase sequencing with one authoritative deadline per phase
- Inclusive exact-deadline semantics
- Heart loss, elimination → spectator, winner/halt paths
- Reconnect/resume snapshot path and lease ownership concepts
- Dev fixtures and bots where match-rules docs allow
- Simulation coverage for core realtime behavior

## Product rules established here

- Server decides accepted input, hearts, energy accounting hooks, elimination, and winner
- One effective submission per player per challenge
- Network arrival order is not presented as skill
- Exact deadline is inclusive
- Zero hearts means spectator, not removal from the experience
- A resumed connection takes ownership from the older socket without losing the player

## Out of scope (historical; still incomplete until later milestones)

- Challenge Studio and versioned content publishing

## Acceptance (historical — already satisfied)

- Authoritative match lifecycle works for six seats under the realtime contracts
- Inclusive deadline and duplicate-submission safety exist for the shipped engine path
- Reconnect restores match identity without inventing a second player under the core rules
- Shared contracts remain the protocol source of truth

## Handoff

Preserve the gateway, engine, store, and contracts. LH-005+ must extend them. Do not fork a second match protocol.
